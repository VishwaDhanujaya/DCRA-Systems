# Department of Christian Religious Affairs
## Free of Charge Medical Letter Issuing System System

A pure PHP and Tailwind CSS system designed for staff at the Department of Christian Religious Affairs for managing priesthood identity cards and passport recommendation certifications.

### Core Theme Colors
- Primary Maroon: `#4E0000`
- Secondary Navy: `#13273F`
- Government Gold Accent: `#D4AF37`

### Project Structure
- Main user/staff facing pages are kept at **root** (`index.php`, etc.).
- Static resources are stored under **`assets/`** (`css/`, `js/`, `images/`).
- Modular logic and layout partials are stored under **`includes/`** (`header.php`, `sidebar.php`, `footer.php`, `config.php`, `db.php`, `functions.php`, `auth.php`).
- Agent rules & skills are maintained in **`.agents/`** (`AGENTS.md`, `phppro`, `impeccable`).
